# Banglish to Bangla Typing Tool

Banglish (English phonetic) to Bangla converter.

Type English like:
valo ase

Get Bangla output:
ভালো আছে

## Features
- Easy to use
- Fast typing
- Mobile friendly

## Usage
Type → Convert → Get Bangla
